## Required citation

When you use this dataset — including indirectly, by training or
evaluating a model with `app/ml/train.py` / `app/ml/evaluate_real.py`
against it — cite:

> Trujillo-Acatitla, R., Tuxpan-Vargas, J., Ovando-Vazquez, C., &
> Monterrubio-Martinez, E. (2024). *Sentinel-1 SAR Oil spill image dataset
> for train, validate, and test deep learning models* (Parts I–III).
> Zenodo. https://doi.org/10.5281/zenodo.8346860

`app/ml/dataset.py::DATASET_CITATION` and `DATASET_DOIS` hold this same
citation/DOI information in code, and `app/ml/train.py` embeds it directly
into every checkpoint's model-metadata sidecar file, so any model card,
report, or UI surface generated by this pipeline can (and does) attribute
the dataset automatically wherever it reports real-data training
provenance (see `MODEL_CARD.md`, the PDF/JSON/CSV report generator, and the
`/api/ml/status` endpoint).
